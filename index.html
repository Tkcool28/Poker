Online mode needs internet on both phones and loads one small library (PeerJS). Keep the host's tab in the foreground — if Terry's phone locks or switches apps, the free signalling server can drop the room. If Online keeps failing, Local mode connects phone-to-phone with no server at all, and works even with no internet.

Not connected

Host (one phone): tap Create offer, copy the code, send it to the other phone any way you like — text, a note, read it out loud. It works over a hotspot with no internet at all, as long as both phones are on the same hotspot/Wi-Fi.

Guest (other phone): paste the host's offer below, tap Create answer, send the answer code back to the host.

Host, last step: paste the guest's answer code below and tap Finish connecting.

Offline tip: load this page while you still have internet, then leave the tab open. On the plane, one phone turns on its hotspot, the other joins it, and Local mode connects over that hotspot — no internet needed after the page is loaded.

Solo starts immediately. Online / Local games start automatically once the other phone connects.
